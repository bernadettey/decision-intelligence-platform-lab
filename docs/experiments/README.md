# Experiments

This folder records project experiments and implementation comparisons.

Use it for notes such as:

- Codex vs Claude workflow comparisons.
- Agent framework trials.
- Evaluation prompt experiments.
- Model behavior observations.
- Data or metric design experiments.

Each experiment should state:

- Question.
- Setup.
- Result.
- Decision.
- Follow-up.

Do not use this folder for source code that belongs in the main application.
